# Every tool and every page, divided across the automations

Sir's rule: growth and traffic work must ALL be covered, and nothing may be
duplicated. This file is the single map. Each **tool** (`tools/*.py`) and each
**page type** has exactly one owning automation. A run reads only its own rows.
If a tool is not listed, it is a build step owned by `rebuild.sh`, not a daily
task.

## Hard rules that never change
- The agent PREPARES. It never posts to Quora, Reddit, Medium or LinkedIn,
  never sends an outreach email, never submits a directory listing, never buys
  a link. Sir sends and submits from his own accounts.
- Never claim to have used a tool that needs a login (Ahrefs, SEMrush, Yoast
  UI, GMB, HARO). The free substitutes above are what actually runs.
- Never write a blog post or news story outside `daily guide` / `daily news`.
- One tool, one owner. If two runs need it, the second reads the first's output.
