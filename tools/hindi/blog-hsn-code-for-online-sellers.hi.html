अगर आप भारत में ऑनलाइन बेच रहे हैं, तो अंकों की एक छोटी सी श्रृंखला तय करती है कि आप कितना tax वसूलेंगे, marketplace आपसे कितना लेगा, और parcel सीमा पार करे तो क्या होगा. यही श्रृंखला आपका HSN code है.

ज़्यादातर नए sellers किसी मिलती-जुलती listing से code copy कर लेते हैं, या platform को चुनने देते हैं, और फिर उसे दोबारा नहीं देखते. यह guide बताती है कि code असल में क्या करता है, वह GST rate से कैसे जुड़ता है, और ऐसा code कैसे चुनें जिसे notice आने पर आप सही ठहरा सकें.

HSN code असल में क्या होता है

HSN का पूरा नाम Harmonised System of Nomenclature है. यह product श्रेणियों की एक अंतरराष्ट्रीय सूची है जिसे World Customs Organization रखता है, और लगभग हर देश जो माल का व्यापार करता है उसे इस्तेमाल करता है.

वैश्विक code छह अंकों तक जाता है. भारत GST के लिए दो अंक और जोड़ता है, इसलिए पूरा भारतीय code आठ अंकों का होता है. अंक कदम-दर-कदम product को संकरा करते हैं:

  • पहले दो अंक chapter हैं. जैसे chapter 61 बुने हुए कपड़े हैं.
  • अगले दो अंक उस chapter के भीतर heading हैं. यही छह अंकों का अंतरराष्ट्रीय code है.
  • आखिरी दो अंक भारत का अपना sub-heading हैं, और GST rate असल में इसी पर तय होता है.

तो code आपके brand या कीमत का बयान नहीं है. यह एक दावा है कि माल वास्तव में क्या है.

Code आपका GST rate कैसे तय करता है

GST rate slab के हिसाब से लगता है, और slab आपके price tag से नहीं, HSN code से जुड़ी होती है. मुख्य slabs हैं 0%, 5%, 12%, 18% और 28%.

  • 0% में ताज़ा उपज, unbranded अनाज और ज़रूरी चीज़ों की छोटी सूची आती है.
  • 5% में रोज़मर्रा का ज़्यादातर माल आता है, जिसमें कपड़ा और सस्ते garments शामिल हैं.
  • 12% और 18% में बना हुआ और packaged माल का बड़ा हिस्सा आता है.
  • 28% luxury और sin goods की एक संकरी सूची के लिए है.

एक ही shelf पर रखी दो चीज़ें, एक ही कीमत पर बिकती हुईं, अलग tax दे सकती हैं — सिर्फ इसलिए कि उनके codes अलग chapters में पड़ते हैं. इसीलिए code कीमत से कहीं ज़्यादा मायने रखता है.

एक उदाहरण: ₹6,000 का order

मान लीजिए आप कोई चीज़ tax से पहले ₹6,000 में बेचते हैं, और आपको पक्का नहीं कि वह 5% slab में आती है या 18% slab में.

  • 5% पर GST ₹300 है. ग्राहक ₹6,300 देता है.
  • 18% पर GST ₹1,080 है. ग्राहक ₹7,080 देता है.

एक ही order पर अंतर ₹780 का है. अगर आपने कम rate पर tax वसूला, पर सही code ऊँचे rate का है, तो वह ₹780 सीधे आपके margin से जाता है, क्योंकि tax तो भरना ही पड़ेगा.

Apparel में यही जाल छोटे पैमाने पर दिखता है. Readymade garments पर ₹1,000 तक की कीमत पर 5% लगता है, और उससे ऊपर 12%. इस रेखा को एक रुपया पार कीजिए और पूरे garment पर rate दोगुने से ज़्यादा हो जाता है, इसलिए कीमत में छोटा बदलाव tax को कीमत के बदलाव से भी ज़्यादा हिला सकता है.

Sellers गलत code क्यों चुनते हैं

गलत code चुनना शायद ही कभी बेईमानी होती है. यह आम तौर पर चार आदतों से आता है:

  • प्रतिद्वंद्वी की listing copy करना. सामने वाले का code गलत हो सकता है, और ऐसा गलत हो सकता है जो सिर्फ audit में पकड़ में आता है.
  • Platform के default पर भरोसा करना. Marketplace listing जल्दी पूरी करने के लिए category सुझाता है, और वह सुझाव शुरुआत है, फैसला नहीं.
  • "others" heading चुनना. Residual heading सुरक्षित लगती है, पर अक्सर उसमें उससे ऊँचा rate होता है जो आपको इस्तेमाल करना चाहिए था.
  • Material के बजाय product का नाम पढ़ना. Code बताता है कि माल किस चीज़ से और कैसे बना है, यह नहीं कि आप उसे ad में क्या कहते हैं.

Code invoice के आगे भी साथ चलता है

HSN code सिर्फ tax की लाइन तय नहीं करता. वह माल के साथ चलता है:

  • Marketplace fees. Commission slabs category के हिसाब से बँटी होती हैं, और category code से जुड़ी होती है, इसलिए code चुपचाप तय करता है कि platform कितना रखेगा.
  • Customs. Import पर वही code सीमा पर लगने वाली customs duty और IGST तय करता है.
  • Invoices. Turnover सीमा पार करते ही हर tax invoice पर code छपना ज़रूरी होता है.

इसलिए एक गलत अंक आपका tax, आपकी platform fee और आपकी landed cost — तीनों एक साथ बढ़ा सकता है.

अपना HSN code कैसे ढूँढें

Listing से नहीं, माल से शुरू कीजिए:

  1. Chapter से शुरू करें. Official GST rate finder में product का नाम खोजिए और देखिए कौन-कौन से chapters आते हैं.
  2. Chapter notes पढ़ें. वे बताती हैं कि chapter में क्या शामिल है और, ज़्यादा काम की बात, क्या शामिल नहीं है.
  3. Material और उपयोग पर मिलाइए. वह heading चुनिए जो बताती है कि चीज़ किससे बनी है और किसलिए है.
  4. Residual heading बाद में आज़माएँ. अगर आप "others" पर पहुँचें, तो लौटकर देखिए कि ऊपर कोई खास heading छूट न गई हो.
  5. लिखकर रखिए. Code, विवरण और वजह एक जगह नोट कीजिए, ताकि एक ही product हर बार एक ही तरह classify हो.

छोटी बात

  • आपका HSN code आठ अंकों का दावा है कि माल क्या है, और GST rate उसी पर टिका है.
  • एक ही कीमत की दो चीज़ें अलग tax दे सकती हैं, क्योंकि slab कीमत नहीं, code के पीछे चलती है.
  • ₹6,000 के order पर 5% slab से 18% slab पर जाने से ₹780 का tax जुड़ता है.
  • Material और chapter notes से classify कीजिए, किसी प्रतिद्वंद्वी की listing या platform default से नहीं.
  • संदेह हो तो एक बार CA से पूछिए और जवाब लिख लीजिए, ताकि एक ही product दो तरह से classify न हो.
