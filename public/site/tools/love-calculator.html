What this calculator is for

The Love Calculator joins Your Name and Their Name into a single string and turns that string into a percentage. It is a name game with its rule in the open: letters only, one fixed weighting, a remainder at the end. Nothing about either person is read, and nothing is predicted. The site labels it entertainment, which is the accurate description rather than a disclaimer bolted on afterwards. The weighting is the part worth understanding. In the joined string the first letter counts once, the second twice, the third three times, and so on to the end, so the last letters of the second name decide most of the answer and the opening letters barely register. "Rahul" with "Priya" scores 38%; swap the order to "Priya" with "Rahul" and the same two people read 94%, because every letter has moved to a new position and been re-weighted. Spaces, dots and digits are discarded before counting, so "Rahul K." scores exactly like "Rahul".

How the maths works

The tool concatenates name1 and name2 in the order typed, lowercases the result, deletes every character outside a to z, then walks the remaining string with an index i starting at 0. For each letter it adds letterCode x (i + 1) to a running total and keeps the total modulo 101, where letterCode is the letter's character code (97 for a, 98 for b, and so on). The remainder after the last letter is the percentage. "RahulPriya" sums to 38 under that rule, so the answer is 38%. Same letters in the same order always return the same number, and the modulo 101 is what holds the output between 0 and 100.

When to reach for it

  • You need a harmless number for a group chat and want it in a single click.
  • You want to prove to someone that spelling alone fixes the score - change one letter and the number moves.
  • You want a worked example of a rule that looks like a prediction but is only arithmetic on letters.

Common mistakes

  • Taking the percentage as a verdict on the relationship. The calculation never sees the people, only the letters they type.
  • Retyping a name in a different way to push the score up. Only the letters and their order count, so the same pair always returns the same number.
  • Assuming a longer name scores higher. The total is a remainder after dividing by 101, so a longer string can land on a smaller number just as easily.
