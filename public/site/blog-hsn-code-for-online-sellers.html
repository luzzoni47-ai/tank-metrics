HSN Code for Online Sellers

Eight digits that quietly set your tax, your platform fee and your duty.

Tax & GSTNovember 3, 2026

If you sell online in India, one short string of digits decides how much tax you collect, what your marketplace charges you, and what happens when a parcel crosses a border. That string is your HSN code.

Most first-time sellers copy a code from a similar listing, or let the platform choose one for them, and never look at it again. This guide explains what the code actually does, how it maps to a GST rate, and how to choose one you can defend if a notice ever arrives.

What an HSN code actually is

HSN stands for the Harmonised System of Nomenclature. It is an international list of product categories maintained by the World Customs Organization, and almost every country that trades goods uses it.

The global code runs to six digits. India adds two more digits for GST, so a full Indian code is eight digits long. The digits narrow the product down in steps:

  • The first two digits are the chapter. Chapter 61, for example, is knitted apparel.
  • The next two digits are the heading inside that chapter. That is the six-digit international code.
  • The last two digits are India's own sub-heading, which is what the GST rate is actually keyed to.

So a code is not a description of your brand or your price. It is a claim about what the goods physically are.

How the code sets your GST rate

GST is charged by rate slab, and the slab is attached to the HSN code, not to your price tag. The main slabs are 0%, 5%, 12%, 18% and 28%.

  • 0% covers fresh produce, unbranded staples and a short list of essentials.
  • 5% covers most everyday goods, including fabric and cheaper apparel.
  • 12% and 18% cover the bulk of manufactured and packaged goods.
  • 28% is reserved for a narrow set of luxury and sin goods.

Two items can sit on the same shelf, sell for the same price, and attract different tax, purely because their codes fall in different chapters. That is why the code matters far more than the price.

A worked example: a ₹6,000 order

Suppose you sell an item for ₹6,000 before tax, and you are unsure whether it belongs in the 5% slab or the 18% slab.

  • At 5%, the GST is ₹300. The customer pays ₹6,300.
  • At 18%, the GST is ₹1,080. The customer pays ₹7,080.

The gap is ₹780 on a single order. If you collected tax at the lower rate but the correct code is the higher one, that ₹780 comes straight out of your own margin, because the tax still has to be paid.

Apparel shows the same trap at a smaller scale. Readymade garments are taxed at 5% up to a selling price of ₹1,000, and 12% above it. Cross that line by one rupee and the rate on the whole garment more than doubles, so a small change in price can move the tax by more than the price change itself.

Why sellers pick the wrong code

Getting the code wrong is rarely dishonest. It usually comes from one of four habits:

  • Copying a competitor's listing. A rival's code may be wrong, and it may be wrong in a way that only shows up at an audit.
  • Trusting a platform default. A marketplace suggests a category to speed up listing, and the suggestion is a starting point, not a ruling.
  • Choosing the "others" heading. A residual heading looks safe, but it often carries a higher rate than the specific heading you should have used.
  • Reading the product name instead of the material. A code describes what the goods are made of and how they are made, not what you call them in the ad.

The code follows you past the invoice

The HSN code does more than set the tax line. It travels with the goods:

  • Marketplace fees. Commission slabs are grouped by category, and the category is tied to the code, so the code quietly sets what the platform keeps.
  • Customs. On an import, the same code drives the customs duty and the IGST charged at the border.
  • Invoices. Once your turnover crosses the threshold, the code must be printed on every tax invoice you issue.

One wrong digit can therefore raise your tax, your platform fee and your landed cost at the same time.

How to find your own HSN code

Work from the goods, not from the listing:

  1. Start with the chapter. Search the official GST rate finder by the product name and note which chapters come up.
  2. Read the chapter notes. They say what the chapter includes and, more usefully, what it excludes.
  3. Match on material and use. Pick the heading that describes what the item is made of and what it is for.
  4. Only then try a residual heading. If you land on "others", go back and check you have not missed a specific heading above it.
  5. Write it down. Keep the code, the description and the reason in one note, so the same product is classified the same way every time.

The short version

  • Your HSN code is an eight-digit claim about what the goods are, and the GST rate hangs off it.
  • Two products at the same price can pay different tax, because the slab follows the code, not the price.
  • On a ₹6,000 order, moving from the 5% slab to the 18% slab adds ₹780 of tax.
  • Classify from the material and the chapter notes, not from a competitor's listing or a platform default.
  • When in doubt, ask a CA once and record the answer, so the same product is never classified two ways.

HSN code asal mein kya hota hai

HSN ka pura naam Harmonised System of Nomenclature hai. Yeh product shreniyon ki ek antararaashtreey sooche hai jise World Customs Organization rakhta hai, aur lagabhag har desh jo maal ka vyaapaar karta hai use istemal karta hai.

Vaishvik code chhah ankon tak jaata hai. Bhaarat GST ke liye do ank aur jodata hai, isliye pura bhaarateey code aath ankon ka hota hai. Ank kadam-dar-kadam product ko sankara karte hain:

  • Pehle do ank chapter hain. Jaise chapter 61 bune hue kapade hain.
  • Agle do ank us chapter ke bheetar heading hain. Yahi chhah ankon ka antararaashtreey code hai.
  • Aakhire do ank bhaarat ka apna sub-heading hain, aur GST rate asal mein isi par tay hota hai.

To code aapke brand ya keemat ka bayaan nahi hai. Yeh ek daava hai ki maal vaastav mein kya hai.

Code aapka GST rate kaise tay karta hai

GST rate slab ke hisaab se lagta hai, aur slab aapke price tag se nahi, HSN code se jude hoti hai. Mukhya slabs hain 0%, 5%, 12%, 18% aur 28%.

  • 0% mein taaza upaj, unbranded anaaj aur zaroore cheezon ki chhoti sooche aate hai.
  • 5% mein rozamarra ka zyadatar maal aata hai, jismein kapada aur saste garments shaamil hain.
  • 12% aur 18% mein bana hua aur packaged maal ka bada hissa aata hai.
  • 28% luxury aur sin goods ki ek sankare sooche ke liye hai.

Ek hi shelf par rakhe do cheezein, ek hi keemat par bikate hueen, alag tax de sakate hain — sirph isliye ki unake codes alag chapters mein padate hain. Iseelie code keemat se kaheen zyada maayne rakhta hai.

Ek udaharan: ₹6,000 ka order

Maan lijiye aap koi cheez tax se pehle ₹6,000 mein bechte hain, aur aapko pakka nahi ki woh 5% slab mein aate hai ya 18% slab mein.

  • 5% par GST ₹300 hai. Graahak ₹6,300 deta hai.
  • 18% par GST ₹1,080 hai. Graahak ₹7,080 deta hai.

Ek hi order par antar ₹780 ka hai. Agar aapne kam rate par tax vasoola, par sahe code oonche rate ka hai, to woh ₹780 seedhe aapke margin se jaata hai, kyunki tax to bharana hi padega.

Apparel mein yahi jaal chhote paimaane par dikhta hai. Readymade garments par ₹1,000 tak ki keemat par 5% lagta hai, aur usse upar 12%. Is rekha ko ek rupaya paar keejie aur poore garment par rate dogune se zyada ho jaata hai, isliye keemat mein chhota badlav tax ko keemat ke badlav se bhi zyada hila sakta hai.

Sellers galat code kyon chunate hain

Galat code chunana shaayad hi kabhi beemaane hoti hai. Yeh aam taur par chaar aadaton se aata hai:

  • Pratidvandve ki listing copy karna. Saamane wale ka code galat ho sakta hai, aur aisa galat ho sakta hai jo sirph audit mein pakad mein aata hai.
  • Platform ke default par bharosa karna. Marketplace listing jaldi poore karne ke liye category sujhaata hai, aur woh sujhaav shuruaat hai, phaisala nahi.
  • "Others" heading chunana. Residual heading surakshit lagti hai, par aksar usamen usse ooncha rate hota hai jo aapko istemal karna chahiye tha.
  • Material ke bajaay product ka naam padhna. Code batata hai ki maal kis cheez se aur kaise bana hai, yeh nahi ki aap use ad mein kya kahte hain.

Code invoice ke aage bhi saath chalta hai

HSN code sirph tax ki laain tay nahi karta. Woh maal ke saath chalta hai:

  • Marketplace fees. Commission slabs category ke hisaab se bante hoti hain, aur category code se jude hoti hai, isliye code chupchaap tay karta hai ki platform kitna rakhega.
  • Customs. Import par wahi code seema par lagane wali customs duty aur IGST tay karta hai.
  • Invoices. Turnover seema paar karte hi har tax invoice par code chhapana zaroore hota hai.

Isliye ek galat ank aapka tax, aapki platform fee aur aapki landed cost — teenon ek saath badha sakta hai.

Apna HSN code kaise dhoondhen

Listing se nahi, maal se shuru keejie:

  1. Chapter se shuru karein. Official GST rate finder mein product ka naam khojie aur dekhie kaun-kaun se chapters aate hain.
  2. Chapter notes padhein. Ve bataate hain ki chapter mein kya shaamil hai aur, zyada kaam ki baat, kya shaamil nahi hai.
  3. Material aur upayog par milaaie. Woh heading chunie jo bataate hai ki cheez kisase bane hai aur kisalie hai.
  4. Residual heading baad mein aazamaaen. Agar aap "others" par pahunchen, to lautakar dekhie ki upar koi khaas heading chhoot na gayi ho.
  5. Likhakar rakhie. Code, vivaran aur vajah ek jagah not keejie, taaki ek hi product har baar ek hi tarah classify ho.

Chhoti baat

  • Aapka HSN code aath ankon ka daava hai ki maal kya hai, aur GST rate usi par tika hai.
  • Ek hi keemat ki do cheezein alag tax de sakate hain, kyunki slab keemat nahi, code ke peechhe chalti hai.
  • ₹6,000 ke order par 5% slab se 18% slab par jaane se ₹780 ka tax judta hai.
  • Material aur chapter notes se classify keejie, kisi pratidvandve ki listing ya platform default se nahi.
  • Sandeh ho to ek baar CA se poochhie aur jawab likh lijiye, taaki ek hi product do tarah se classify na ho.
